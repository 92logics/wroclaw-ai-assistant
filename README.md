# Wrocław AI assistant (prototype)

Scripted sample by [92 Logics](https://www.92logics.com) for the University of Wrocław virtual assistant (BZP.272.16.2026.ECS). It is not an official university system and not a bid.

Live page: https://92logics.github.io/wroclaw-ai-assistant/

## What it shows

- Polish and English
- A public module for foreign applicants
- A closed module for enrolled foreign students (sample preview only, no sign-in)
- Scripted answers only. Nothing calls a live AI service.

Notice: https://platformazakupowa.pl/transakcja/1353639

## Run it

Open `index.html` in a browser. No install and no build step.
